# Fraunces display-font source

The active display family is Fraunces Variable by the Fraunces Project Authors (Undercase Type, Phaedra Charles and Flavia Zimbardi). Instrument Sans Variable remains the reading and UI family.

- Distribution: `@fontsource-variable/fraunces` version 5.3.0, Fontsource's Google Fonts distribution (metadata font version v38).
- Exact imported file: `files/fraunces-latin-full-normal.woff2`.
- Bytes: 121016.
- SHA-256: `7e744849028e2219e2aa1bc467dc4032980dc4487c9c3da3010081cd72d3b103`.
- Style/subset: upright normal, Latin. No italic or additional-subset CSS is imported.
- Available normal-font axes: weight 100–900, optical size 9–144, softness 0–100 and wonk 0–1.
- Portfolio treatment: ordinary CSS weights 400–500 for main display type; optical size follows text size; softness 0 and wonk 0 stay steady at the distribution's neutral defaults. No axis animation. The font's supported weight range is declared unchanged.
- The font binary is imported directly by typography.css and self-hosted by the existing Vite build. It is not edited or renamed internally.
- `fraunces-OFL.txt` is an exact copy of the installed distribution's LICENSE and includes the original copyright notice and complete SIL Open Font License 1.1.
- Earlier Syne and Pixelify assets/licenses remain in the repository. Their font faces are not active in the current two-family typography system.
