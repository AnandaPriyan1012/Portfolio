# C21: follow an Admissions note into the real detail

A fresh review of the live C20 release selected CIRS's practical Admissions
proof. Work showed three inert structure entries; the case offered matching
image notes, but a phone selection was only about 53×12px. Opening the larger
capture and choosing actual size started at the image's top-left, with the
already-chosen Portal still below the visible inspection area. Existing modal
closure and focus worked. This was an opportunity to carry a deliberate choice
into a readable original, rather than a broken-image or scrolling claim.

Work's existing Application portal, Admissions process and School enquiries
entries are now native image-note controls. They reuse the case study's exact
1440×1000 screenshot, coordinate bounds and explanatory observations. The full
image, original caption, project introduction, Quick view, case link and live
Admissions link remain. Selecting a note highlights that real source region and
explains its purpose; it does not submit an application or simulate the school
portal. Current availability and arrangements still belong to Admissions.

The ordinary View larger capture action remains available. A selected note also
offers Inspect Portal/Process/Enquiries detail. That action opens the same whole
original image, waits for decoding and validates its natural dimensions, then
shows its original pixel size and makes one bounded pan to the chosen region.
It centres a small region when possible and begins at the leading edge of a
region larger than the viewport, with a small reading margin. Enquiries is
961px wide, so native panning remains necessary on a phone. Nothing is cropped,
resized into a fictional readable screenshot, retouched or regenerated.

The selected note remains identified in the caption. Whole-image fit, manual
actual-size zoom, the original-image link and native image panning remain. Real
input cancels pending automatic positioning; later resizing does not repeatedly
snap a reader back. A source/dimension failure retains an honest whole-image or
error alternative. No media or external service is loaded by selecting a note.

The inspector records the actual opener for both actions. Its native top layer
and body lock belong to the open/closed session rather than image state changes.
Close/Escape restores that exact control and reading position; history and AP
opening dismissal preserve the navigation coordinator's ownership. Generation
guards invalidate pending decode/position work on close and unmount. A single
bounded frame applies the initial detail pan; there is no new animation loop.

The three Work controls retain their existing layout and obtain local colour
tokens for that page. Work refreshes existing scroll geometry after a committed
note/error layout change. The global scroll controller is unchanged. Ordinary
Atlas, route-deck and bilingual inspection retain their existing intrinsic
action layout; the paired detail layout is scoped to callers that need it.

Validation covers Work and case journeys at desktop, phone and narrow
reduced-motion sizes, settled source-coordinate alignment, readable natural
scale, oversized native panning, both openers, whole fit, held-source input
cancellation, errors, history/AP dismissal, manual pan/resize and accessible
keyboard/forced-colour alternatives. Existing ordinary-inspector, image-note
and capture-history regressions are checked separately. Exact local/public
results, screenshots and deployment identity are recorded under
`/workspace/cycle-twenty-one-release-review`.
An initial Escape assertion observed a natively closed dialog before its queued
close event completed React cleanup. The retained temporal probe showed the
body unlock and DOM removal correctly settling, with focus and Y unchanged.
The check now waits for that actual completion and verifies stable results;
no production change was needed for that readiness issue.

The original Admissions capture is distinct from the newer Interface Atlas
capture; the existing bounds were not applied to a replacement image. All
original media, films, frame derivatives, AP assets, project credits and
recognition qualifications remain. No dependency, font, sharing permission or
global scroll owner was added. The prior Library materialization HTTP 401 was
not retried; unavailable certificate originals and unmatched MUN material remain
unpublished.
