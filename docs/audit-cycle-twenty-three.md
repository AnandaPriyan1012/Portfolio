# C23: put the real work in the opening

A fresh review of all four main pages and the major project stories selected
Home's first impression as the largest creative opportunity. The existing
opening gave nearly the entire desktop view to generated architecture and the
phone view to an abstract glass shape. The genuine CIRS interface began as a
small browser in the corner. Vallalar and AccuFlow appeared later as choices
inside the directory, whose default repeated CIRS. The portfolio already had
specific project evidence; its first visual statement did not express that
breadth or the different reasons for making the work.

The existing opening now becomes an original composition around real interface
specimens. School, community and a student idea have distinct purposes and
materials within the same black, gold and glass identity. Ananda's name and
personal roles remain the introduction. The secondary Studio route makes film
work easy to find alongside the primary Work action. This replaces the abstract
subject of the opening rather than adding another section or full case study.

CIRS retains its existing decoded Campus and Admissions proof, source links,
manual choices, case destination and return behavior. The school-team context
remains clear. Vallalar uses an actual website review-preview capture alongside
its voluntary-work context, since 2023; no service photograph or official launch
is invented. AccuFlow uses its real initial guide interface, explicitly a website
and interaction prototype. It does not demonstrate product availability, AI
responses, clinical results or a newly inferred personal role.

The two additional glass plates unfold inside the existing Home ScrollTrigger
timeline and give way to the readable CIRS scene. There is one existing pin,
unchanged runway and scroll owner where the composition fits. A Home-only
capability query gives smaller or short windows normal flow; other pages keep
their existing motion gates. No new animation loop, scrolling library,
3D navigation requirement or storage key is introduced. The initial CIRS image
is fully opaque. Source pixels remain intact and contained within their frames;
there is no regenerated project artwork or fictional before/after comparison.

Phones and quiet layouts use ordinary document flow, compact project specimens
and the same readable CIRS proof. The purpose and status text remain ordinary
HTML. Existing licensed typography supplies the more expressive hierarchy;
forced-system colours, focus indication and native navigation remain available.
An actual reduced-motion transition exposed the new film link losing focus
when the pin was removed. The existing Home-only focus snapshot now covers the
whole opening, including its native actions. Its actual-focus, connected-node,
focused-document and BODY-only restoration guards remain, and outside input
clears ownership. No delayed focus loop or other-page focus owner was added.
Generated room and Flow assets are preserved in the repository, with their
original marks and provenance. They are simply no longer the active Home
background, and no atmospheric MP4 is needed for the opening.

Validation covers actual forward/reverse wheel staging, source and status
alignment, responsive composition, quiet and forced modes, image failures,
Work/Studio navigation, CIRS case returns and the preserved proof's independent
selection behavior. Existing room/Flow-specific test expectations are updated
only where this intentional subject change makes them obsolete. Other observed
legacy failures are compared against the preserved C22 runtime rather than
silently attributed to this change. Exact candidate/public results and actual
screenshots are recorded in `/workspace/cycle-twenty-three-release-review`.
First rendered review also caught older offset rules shifting the phone copy
and edition line over the new composition. Explicit scoped resets correct
those conflicts; the desktop prototype plate was raised to keep its complete
caption visible. A missing Unicode link glyph was replaced with an existing
SVG icon. The original failed screenshots and test output remain available.
Six maintained layout tests also contained an older header-only Work jump
expectation. An exact archived C22 comparison reproduced the same 75.6–75.7px
gap: the existing C17 chapter rail accounts for 56px of it. Those assertions
now measure the actual header plus rail, retaining their 16–40px clearance
range. No Work navigation behavior changed for this maintenance.

The Work, Studio, About and case-story content, exact AP logo, original films,
frame derivatives, source captures, credits and qualified recognition records
remain. No new media, font, dependency or sharing permission is needed. The
unresolved Library materialization HTTP 401 was not retried without new access;
unavailable certificate originals and unmatched MUN material remain unpublished.
