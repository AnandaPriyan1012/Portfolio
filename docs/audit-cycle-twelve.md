# C12: make project context and navigation readable

Independent reviews of the live C11 release found three concrete problems.
Phone Work links hid their project notes, leaving important readiness distinctions
outside the accessible link text. The pale CIRS surface retained pale text in
light mode, affecting its purpose/contribution brief, actions and reconstructed
study. Footer Back to top moved the visual page while leaving native focus at the
footer, so the next keyboard move could jump straight back down.

The Work index now names each project's purpose and stage in ordinary visible
link text. CIRS concerns campus life and Admissions on the live official school
website; Vallalar combines website/digital-storytelling work with voluntary
involvement since 2023 and a website review preview; AccuFlow is a six-page
website/conversational-guide exploration. The selected image labels identify
the actual homepage, About-page preview or Try-interface capture. The shared
proof pane, three native chapter links and original assets remain. Phone status
and purpose text are at least 10px; the desktop index remains about 336px high.
No product outcome, clinical claim or new contribution was added.

CIRS's light brief, controls and concept-drawer summary now use dark-green text
on the pale material. The opened optional study keeps its existing light text
and dark image captions on a scoped charcoal glass surface. Its explanation
that this is a portfolio interpretation rather than an original project sketch
is readable. Forced colors retain native Canvas/CanvasText and focus treatment.
The other two project chapters keep their dark materials and existing text
palette. This is a scoped correction, not a global inversion of project text.

The Vallalar and AccuFlow image buttons now accurately announce Quick view and
their dialog popup. Their behavior stays unchanged; full case-study links still
lead to the dedicated pages. Keyboard checks confirm the dialog preserves the
current chapter and returns focus to the image action when closed.

Back to top now places native focus at the page heading, or Home's persistent
main landmark because its animated heading can be hidden at the footer. Keyboard
activation places the page at zero immediately; pointer activation retains the
existing smooth return. The shared scroll helper's optional immediate flag keeps
other calls unchanged. No completion-time focus retry can override a visitor's
next key. Native modified/middle activation, history and current film fragments
are preserved, and the separate case-study footer remains untouched.

Public verification exposed a native-focus race that the first local run did
not catch: focus could scroll to the footer before Lenis consumed the scroll
event, leaving its cached target at zero. A top request could then be ignored as
redundant. The numeric scroll path now refreshes Lenis's dimensions and actual
position before requesting a target, as the existing element path already did.
Two same-task native focus/activation regressions reproduced both failures before
the correction. The public failure evidence is retained with the release checks.

All exact AP assets, original films and C11 frame derivatives, approved
source gates, Gaurav qualifications and private-source exclusions remain. No new
media or dependencies were introduced. The prior Library materialization HTTP
401 was not retried and no Drive sharing changed.

The initial 130 combined checks passed. After the public race correction, all
74 focused navigation, Back-to-top, history and scroll-scene checks passed,
including the two regressions that failed before the fix. The final
build/typecheck, three cache checks and original-film/frame integrity checker
passed. Independent fixed-build review passed twelve Back-to-top flows and four
repeated trusted-input timing probes; the nine visual/status/dialog flows retain
the same verified CSS. The corrected light brief sampled at least
5.31:1 against its rendered backgrounds; the opened study's description and
controls sampled above 7:1. Other dark project briefs retain their contrast.

Exact compiled/public results are recorded separately under
`/workspace/cycle-twelve-release-review`; a local build alone does not establish
publication.
