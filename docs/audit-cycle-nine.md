# C9: give each project its own evidence

An independent review of the C8 live release covered Work and the CIRS,
Vallalar and AccuFlow cases at 1440, 390 and 320px. Vallalar's case described two
languages while showing only one capture; AccuFlow's case described a journey
but left its four-route explorer on Work. On phones, CIRS Admissions reduced to
268×186px at 320px, and several project/source links had 24–35px tap heights.

The cases now contain indexed, project-specific evidence chapters: Vallalar's
actual English/Tamil review preview; AccuFlow's actual Homepage, Product,
How it works and Guide captures; and the approved 38-second CIRS website-launch
film poster with a matched Studio link. Evidence remains available in both
reading cuts. The film link selects only a ready canonical entry and leaves
playback behind the existing explicit Watch action. It adds no production
credits or standalone Crossroads attribution.

Work retains its hero scenes, briefs, source images and case links. Its three
full viewers are now optional native drawers. Validated, bounded per-tab
preferences preserve drawer state and selected views across case returns and
reloads, with a memory fallback if storage is denied. An explicit return from a
native Work project link now restores that link's focus as well as position.
Vallalar's purpose copy uses the already-sourced progression from meal service
to the organisers' request for an online presence. The unused internal editorial
attribute was removed. No reach, outcome or translation-authorship claim was
added.

Capture inspection uses the existing local files: whole-image fit, original
pixel size, native scrolling and a direct original-image link. The selected
language or route supplies its matching phone capture; the AccuFlow homepage
keeps its explicitly documented desktop fallback. CIRS's annotation coordinates
stay on their original 1440×1000 image. Native dialog focus, touch exit and AP
top-layer cleanup are covered by dedicated checks. The inspector adds no
generated or retouched images, film requests or third-party requests before
explicit interaction. The affected mobile project/source links now meet the
existing 44px target convention.

The independent combined-build review measured default Work heights of
6,019/7,383/7,422px at 1440/390/320px, compared with 8,013/10,091/9,990px in its
matched C8 baseline. Full viewers remain available on demand. These are layout
measurements, not field loading or conversion claims.

Validation and exact compiled/public release evidence are recorded separately.
The initial broad 337-check run passed 335 and exposed an outdated progress
percentage assumption and a partly tilted annotation comparison. Final checks
retain exact annotation bounds and test semantic chapter progression. An extra
real two-axis touch probe also found Close clicking through to the page beneath;
touch compatibility-click handling is corrected before publication.

Gaurav's C8 restoration and source qualifications, original media and AP bytes,
private-source exclusions, approved playback gates, cache/404 policy and legacy
Netlify site are preserved. The Library materialization operation remains
blocked by its prior HTTP 401 and was not retried. No Drive permissions changed.
