# Requested glass layout restoration and retro styling

This is a bounded response to the owner's request to remove the Gaurav award,
slow the animation and keep the earlier luxurious layout with retro video-game
styling. It does not resume continuous portfolio work. Publication was explicitly
authorized after testing.

The Home composition is restored from the earlier `a1fc479` version: warm glass
architecture, a transparent optical pane, the original name/introduction and
primary action, and the small genuine CIRS browser that expands on scroll. The
intervening project-board layout is removed. A photographic cinema draft was
superseded before publication when the owner clarified the direction; it is not
part of the site.

Retro styling is deliberately applied to the existing composition. The name,
kickers and principal button use the already licensed and self-hosted Pixelify
font. A restrained static raster sits inside the optical pane, and the main
button has a warm pixel-like bezel. Body copy remains readable continuous type.
The other pages, project evidence and established navigation are preserved.
The native Films link remains available; it does not invent a new video or credit.

The opening retains one scroll owner and one pin. Its runway increases from 110%
to 160% of the viewport. The title holds through 28% and uses one gradual fade to 66%,
removing the old compounded support/title fades. The familiar CIRS browser starts
its main expansion at 48%, finishing at 88%. Its source dissolve runs from 74–90%,
with the dominant-source label switching at 82%. Reflection and atmosphere give
way gradually; reverse scroll uses the same path. Quiet, forced, touch and small
windows retain normal-flow proof and native controls.

The decorative glass film plays at 0.75 rate. Its entire original frame, required
mark and source bytes remain intact. Real portfolio films retain their original
playback speed. Deliberate smooth anchor navigation uses 1.2 seconds instead of 0.85;
native wheel/touch and immediate restoration remain responsive. The AP page
curtain now fades during the final 220 ms of its existing 1600 ms lifetime. Skip,
Escape, wheel and touch intent still dismiss it immediately; no loading delay,
body lock or new animation loop was introduced.

The Gaurav object is removed from active content. The other four recognition
objects remain byte-for-byte unchanged. Derived lists and navigation update from
the same array, and affected tests now expect those four records. Historical
audit documentation remains historical evidence rather than visible recognition.
No new personal claims, certificate files or sharing changes are introduced.

Initial browser review caught Pixelify labels wrapping the miniature CIRS
controls at 1100px and consuming its image area. The original control type was
restored while retaining 44px targets; the old preview geometry is unchanged.
Final review explicitly checks positive preview/image height at that boundary.

Validation covers the restored composition, retro typography, source/mark
containment, measured slower wheel pacing and reverse, manual source choices,
responsive/quiet focus, native Work/Films/case returns, finite curtain fade and
immediate dismissal, and award removal. Exact source freezes, local/public
results and actual screenshots are recorded in
`/workspace/requested-hero-revision/release`. The existing Library access blocker
is not retried. Work stops after this authorized release is verified.
