# C10: connect the work, its previews and the reader's next step

An independent review of the C9 release found that Home's selected film and
About's Farewell frame both opened the default Studio entry. The selected
project caption looked interactive but had no action. Home also defined genuine
phone captures without displaying them, while the CIRS scene linked only to the
external school website. These were gaps in the journey through the real work.

Home now gives the selected preview its own native link: the corresponding
project case or a ready, canonical Studio film. The three main page links remain
direct links on the first tap. Preview choices use bounded per-tab preferences
with an in-document fallback when storage is denied. Project returns restore
the original link and position. The real phone captures use a portrait viewing
area, with captions that distinguish a website capture, a review preview and a
prototype. The CIRS browser bar has a separate case-study link at phone and
desktop widths, alongside its existing external website action.

does not qualify a film for a playback-specific link: the existing approved
native or Drive gate must pass. The swimmer's glass plate presents the two
already-sourced personal bests with their CV qualification visible. The relay
record stays in the existing disclosure. No new result, award category,
production credit or outcome was added.

including actual CIRS Admissions, Vallalar review, AccuFlow prototype and trailer
imagery. Keyboard entry reaches the tour, its controls have 44px targets, and
the current chapter pauses while someone focuses or hovers its content. Higher
overlays and hidden pages hold timing; Escape closes the upper view alone.
Manual chapters remain available for reduced motion, forced colors and saved
Motion Off. Explore opens the full project case. The decorative hero also uses
its existing static fallback when forced colors is enabled, including when that
preference changes during a visit.

while restoring the footer's position and native launcher focus. The scroll
