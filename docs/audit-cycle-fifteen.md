# C15: let the opening show the Admissions work

A fresh visual review found a mismatch in Home's existing CIRS reveal. Its
caption named an Admissions focus, but the enlarged browser showed the campus
homepage throughout. The phone version reduced that evidence to a tiny portal.

The existing browser now holds two genuine views of the same school website.
The camera move remains unchanged. Campus stays through progress 0.66, dissolves
into Admissions over 0.66–0.74, and the final quarter remains a stationary reading
hold. No extra pin distance or section is added. Both views use the matching
4 November Atlas captures, with equal reserved dimensions within each device
pair, complete contained images and explicit capture captions. Links, address
and accessible image description follow the actual visible view. These are
different pages, not before/after versions or a claim about current intake.

Native Campus and Admissions controls override scrolling; Follow scroll returns
to the current phase. An explicit choice survives ordinary SPA case returns in
bounded module memory, without new storage/history writes. Focus on a view or
external source protects its destination during scroll. The stable case action
retains its original href and source marker. One failed or delayed image can
retain the other valid proof; both failures request the usable static fallback.

Native, phone and quiet presentations place the full-width proof in normal flow
below the reserved hero artwork and introduction. They retain the same controls
and complete portrait/desktop source, rather than compressing the new controls
into a miniature window. Forced colors use a deliberate quiet alternative on
Home; other pages retain their existing motion policy. All original video bytes
and the visible marked corner remain untouched.

Actual keyboard testing caught pin refresh/reparenting dropping focus after a
successful case return. Home now remembers only its active native proof control
and restores that same connected node synchronously after the public refresh or
media lifecycle, only when focus fell to BODY and the document still owns focus.
Input outside the proof clears the snapshot. The initial snapshot also covers
an already-focused control when animation is re-enabled. No delayed focus retry
can override a reader's next move, and listeners are removed on route cleanup.

Global project assets and the older annotated Admissions tour source are
unchanged: that tour's coordinates still refer to its original capture. The
exact AP, existing personal stories, qualified awards/sports, original films and
frame data remain. No media/dependency, sharing change or retry of the blocked
Library materialization is introduced. Exact compiled/public validation and
earlier failure evidence are recorded under `/workspace/cycle-fifteen-release-review`.

Native tablet layouts use the same readable quiet frame as other non-pinned
views. Forced-colour selected labels use CanvasText/Canvas with a Highlight
outline, retaining a distinct focus outline and readable text.

Validation passed 45 initial regressions, 19 focused post-correction checks,
two deterministic Back-to-top checks, all 17 compiled story checks and nine
repetitions of the pin/focus transitions. Five final scope checks and the updated
evidence-link check passed as well: 98 browser executions across the documented
integration stages. Twelve strict native case returns had zero position drift.
Independent review passed nine visual modes and the full preference/breakpoint/
route cleanup sequence, with exactly one opening trigger in enhanced Home and
none in quiet mode or other pages. Build/typecheck, static entries, cache checks
and unchanged original-film/frame integrity passed. Public results are recorded
separately; a local build alone does not establish publication.
